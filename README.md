# Datheon_Python_Programming_Internship

This repository contains completed tasks for Datheon Python Programming Internship.

## Tasks Completed - All 4 Tasks

### Task 1 - Hangman Game
Console based Hangman game with random word selection, 6 lives, guessed letters tracking. 
File: Task_1_Hangman_Game_Task_1_Hangman/hangman.py
Run: python hangman.py

### Task 2 - Stock Portfolio Tracker
Tracks stock portfolio using hardcoded dictionary {AAPL:180, TSLA:250, GOOGL:140, MSFT:320}. Calculates total investment.
File: Task_2_Stock_Tracker_Task_2_Stock_Port/stock_tracker.py
Run: python stock_tracker.py

### Task 3 - File Organizer
Automates filesystem operations using os and shutil. Sorts files into Images, Documents, Videos, Audios, Codes, Zips, Others.
File: Task_3_File_Organizer_Task_3_File_Orga/organizer.py
Run: python organizer.py

### Task 4 - Chatbot
Rule-based terminal assistant using re (regex) and json (FAQ dataset). Intents: greeting, business hours, product FAQ, contact. Handles bye/exit/quit. Fallback for unknown.
Files: Task_4_Chatbot_Task_4_Chatbotchatbot/chatbot.py + faq.json
Run: python chatbot.py

### Tech Stack
Python 3, random, os, shutil, re, json
